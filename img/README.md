# Add your hero image here

## Requirements:
- Filename: hero.webp
- Recommended size: 1920x1080px
- Format: WebP (for best compression)
- Max file size: 200KB

## How to convert:

Using sharp-cli (recommended):
```bash
npm install -g sharp-cli
sharp -i your-image.jpg -o hero.webp --webp quality=85
```

Using online tools:
- https://squoosh.app/
- https://cloudconvert.com/jpg-to-webp

## Example sources:
- Unsplash.com (search: "memorial", "cemetery", "peaceful")
- Pexels.com (free stock photos)
- Your own photography

⚠️ Ensure you have rights to use the image!
