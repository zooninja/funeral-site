# Изображения за Траурни Атрибути

## Структура на директорията

Добавете изображения за всяка категория в съответните поддиректории:

```
img/
├── kovchezi/          # Снимки на ковчези
├── urni/              # Снимки на урни
├── ventsi/            # Снимки на венци
├── piaflori/          # Снимки на пиафлори
├── draperii/          # Снимки на драперии
├── pametnitsi/        # Снимки на паметници
├── nekrolozi/         # Примери на некролози
└── portreti/          # Снимки на порцеланови портрети
```

## Изисквания за изображенията

- **Формат:** WebP (препоръчително) или JPG
- **Размер:** Оптимално 800x600px
- **Максимален файлов размер:** 200KB
- **Наименование:** описателно име (например: `kovcheg-dub-1.webp`)

## Как да конвертирате изображения

### Използвайки онлайн инструмент:
1. Отворете https://squoosh.app/
2. Качете вашата снимка
3. Изберете WebP формат
4. Настройте качество: 80-85%
5. Свалете оптимизираното изображение

### Използвайки Node.js (sharp):
```bash
npm install -g sharp-cli
sharp -i input.jpg -o output.webp --webp quality=85
```

## Съвети

- Използвайте светли, професионални снимки
- Избягвайте размазани или тъмни изображения
- Уверете се, че имате правата да използвате изображенията
- Добавете описателни имена на файловете за по-добра организация
